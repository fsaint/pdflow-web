## Temporary vs. Permanent Rotation — What's the Difference? {#temp-vs-perm}

This is the most important thing to understand about rotating PDFs on iPhone:

| Type | What It Does | Does It Fix the File? |
|------|-------------|----------------------|
| **Device rotation** | Rotates your iPhone screen | No — view only |
| **Scroll/zoom rotation** | Some apps let you rotate the view | No — resets when you close |
| **File-level rotation** | Edits the PDF structure | Yes — permanent across all apps and devices |

**Rotating your iPhone does nothing to the PDF file.** When you open the same file on a computer or send it to someone else, the pages are still sideways. You need a tool that edits the file — like PDFlow.

Many online guides confuse these two types. If you've "rotated" a PDF before and the problem came back next time you opened it, you only changed the view, not the file.

## Does iPhone Have a Built-In PDF Rotation Tool? {#built-in}

Yes — since iOS 16, the Preview viewer inside the Files app supports permanent page rotation. This is a genuine built-in option that works without any third-party app.

Built-in iOS rotation limitations:
- Works **one page at a time** — no multi-select
- **Overwrites the original file** — no separate export
- Rotates in **90° increments only** — same as PDFlow, which is standard
- **No thumbnail grid** — you rotate while reading, not from an overview

For a single sideways page in a short document, the built-in method works fine. For multiple pages or when you want to keep the original, PDFlow is faster and safer.

## How to Rotate PDF Pages on iPhone Using iOS Preview {#ios-preview}

### Step-by-step

1. Open the **Files** app and locate your PDF
2. Tap to open it in Preview
3. Navigate to the page you want to rotate
4. Tap the **three-dot menu** (or the page indicator at the top) to reveal page options
5. Tap **Rotate Left** or **Rotate Right**
6. The rotation saves automatically

Alternatively, on some iOS versions:
1. Open the PDF in Files
2. Tap the page count to open the thumbnail strip
3. Touch and hold a page thumbnail

## Frequently Asked Questions {#faq}

### Why does my PDF keep rotating back on iPhone?

If the rotation resets every time you open the file, you are only changing the display view — not the file itself. To fix the rotation permanently, you need a tool that edits the PDF structure, like PDFlow. Rotating your iPhone or using pinch/zoom gestures in a PDF viewer does not change the underlying file.

### Can I rotate just one page in a PDF on iPhone?

Yes. PDFlow lets you tap a single page thumbnail and rotate only that page. The rest of the document stays in its original orientation. This is the most common use case — fixing one scanned page that came out sideways while leaving everything else intact.

### How do I rotate a scanned PDF on iPhone?

Scanned PDFs (image-based pages) rotate the same way as any PDF in PDFlow. Open the file, select the pages that are oriented incorrectly, choose the rotation direction, and export. PDFlow rotates the image data embedded in each page.

### Does rotating a PDF affect its quality?

No. PDF rotation changes the orientation metadata and/or the image transform in the file structure — it does not re-render or re-compress the content. Text and image quality are completely unaffected.

### Can I rotate all pages in a PDF at once on iPhone?

Yes. In PDFlow, use the "Select All" option in the Rotate tool to select every page simultaneously, then apply your chosen rotation direction. This is useful for PDFs where every page was scanned in landscape when it should be portrait.

### Will the rotation show correctly when I print the PDF?

Yes. PDFlow performs file-level rotation, which means the corrected orientation is embedded in the PDF itself. It will display and print correctly in every app, on every device, and from any printer.
